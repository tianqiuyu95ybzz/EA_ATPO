# EA-ATPO 动作价值重分析

## 定义

重算输入是原始 3,492 条 Pilot 轨迹，没有训练或合成 rollout。统一临床收益定义为：最终选项正确 `1`，错误或协议无效 `0`。先在每个公开状态、每个动作内平均 3 次 rollout 得到经验 `Q(a,s)`，再以状态为单位选择效用最高动作。无成本最优比例和 gap 基于 291 个状态。

成本效用只扣一次：

`U(a,s) = Q(a,s) − λASK × 患者模拟轮数 − λCONSULT × CONSULT 专家 token/1000 − λDEFER × DEFER 专家 token/1000`

ASK 轮数、CONSULT token 和 DEFER token 均来自完整分支 trace。λ 是人为敏感性单位，不是美元、医生费用或临床效用测量。原 Pilot 中 `outcome` 是未扣成本的 0/1 Q，成本单独保存；本重算没有重复扣费。

成本敏感数据有一个边界：27 个 Expert 协议失败响应没有写入 usage，相关专家成本被记为缺失/观测下界，而不是推测填值。因此下面的成本结果是基于已观测调用成本的敏感性分析；无成本结果不受此问题影响。

## 固定动作准确率

95% 区间以病例为聚类单位 bootstrap；同一病例内的所有状态和重复 rollout 一起保留。

| 动作 | 准确率 | 95% 病例聚类 CI |
|---|---:|---:|
| ANSWER | 41.9% | 33.2%–50.9% |
| ASK | 45.6% | 37.3%–54.0% |
| CONSULT | 44.6% | 36.2%–53.0% |
| DEFER | 44.4% | 35.7%–53.3% |

CONSULT−ANSWER 配对差为 +2.67 个百分点，95% 病例聚类 CI 为 −1.78 到 +7.33 个百分点。该区间跨 0。

## 最优动作分布与 value gap

每格是“最优动作状态占比（95% 病例聚类 CI）”。Gap 是每状态最佳与次佳效用差的平均值，单位为正确率效用百分点。成本设置为 `(λASK, λCONSULT, λDEFER)`。

| 成本组 | 系数 | ANSWER | ASK | CONSULT | DEFER | 最佳−次佳 gap |
|---|---|---:|---:|---:|---:|---:|
| 无成本 | (0, 0, 0) | 77.7% (70.9–84.0) | 10.7% (6.8–15.1) | 6.2% (3.1–9.9) | 5.5% (2.4–8.7) | 9.9 (6.5–13.8) |
| 全部较低 | (0.01, 0.02, 0.02) | 77.7% (71.2–84.1) | 6.9% (3.5–10.6) | 7.6% (4.1–11.4) | 7.9% (4.1–11.9) | 10.9 (7.7–14.5) |
| CONSULT 较贵 | (0.01, 0.10, 0.02) | 77.7% (70.7–84.2) | 6.9% (3.5–10.7) | 7.6% (4.1–11.6) | 7.9% (4.1–12.4) | 10.8 (7.7–14.4) |
| DEFER 较贵 | (0.01, 0.02, 0.10) | 77.7% (70.9–84.1) | 7.2% (3.8–11.0) | 8.9% (5.2–13.2) | 6.2% (3.1–10.0) | 12.2 (9.1–15.7) |
| 全部较高 | (0.03, 0.10, 0.10) | 77.7% (70.9–84.1) | 6.9% (3.5–10.7) | 7.6% (4.1–11.3) | 7.9% (4.1–12.1) | 14.6 (11.6–18.0) |

全量指标和 4,000 次病例聚类 bootstrap 区间见 `outputs/action_value_reanalysis.csv`。同分时按照低实测专家 token、低患者轮数、再按 ANSWER/ASK/CONSULT/DEFER 优先级打破平局。

无成本 Q 下 CONSULT 严格高于另外三动作的状态占 4.8%（95% CI 2.1–8.0），DEFER 为 3.8%（1.4–6.5）；这分别是 291 个状态中的 14 个和 11 个。它们是当前四个采样 rollout 下的经验独立优势状态，不代表潜在/真实临床优势。成本变化会改变优势集合：高 DEFER 惩罚时，CONSULT 严格优势占比升至 8.9%；高 CONSULT 惩罚时，DEFER 严格优势占比为 7.9%。

## 解释限制

- ANSWER 在无成本及所列成本组里都占约 77.7% 的经验最优状态；另外三种动作仍在少数状态上胜出。状态价值的差异是有限重复数下的描述性估计，不是已学习 Router 的泛化结果。
- ASK 分支可在患者提问后继续 CONSULT，初始 CONSULT 分支因一次咨询预算已用尽而不能再次 CONSULT。该资源差异来自现有 Pilot 协议，应作为动作定义的一部分解读。
- 27 个失败仍以 Q=0 纳入所有动作均值。成本未写入的失败 Expert 请求会让成本较高动作的效用被高估；不能据此确定部署时的最优成本策略。
