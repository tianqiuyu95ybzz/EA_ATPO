# EA-ATPO V2 Window B：成本、互补性与可学习性诊断

日期：2026-11-20

数据：50 个合法训练病例、146 个公开状态、438 条 ASK/ANSWER/DEFER 轨迹。

结论范围：仅限这批训练数据的事后诊断，不是 Router 泛化评估。

## 统计方法

- 主要点估计为病例宏平均：先在每个 `case_id` 内平均该病例的公开状态，再对病例等权平均。
- 95% 区间使用 10,000 次病例级 bootstrap；同病例状态始终作为一个簇整体抽样。状态池化数值另列为描述统计，不把 146 个状态当作独立病例。
- 主实验成本固定为 ASK=0.01、ANSWER=0、DEFER=0.05。成本网格为 ASK `[0, 0.01, 0.03, 0.05]` × DEFER `[0, 0.05, 0.10, 0.20, 0.40, 0.60]`。该网格按任务要求预先固定，没有根据结果挑选有利成本。
- Utility 定义为最终正确性减去相应动作成本。所有策略使用完全相同的公开状态和动作结果。
- Oracle 对每个状态用真实动作结果选最大 Utility；并列时在并列动作间均分动作概率。它是使用标签的事后上界，不是可部署策略。

完整的 24 组成本 × 4 种策略指标及其区间见 [`cost_sensitivity.csv`](results_20261120_rerun2/cost_sensitivity.csv)；每组最优动作分布见 [`oracle_action_distribution.csv`](results_20261120_rerun2/oracle_action_distribution.csv)。Accuracy-Utility 图见 [`accuracy_utility_curve.svg`](results_20261120_rerun2/accuracy_utility_curve.svg)。

## 动作互补性

以下百分比为状态比例；区间和病例覆盖均按 `case_id` 聚类。状态数列出全部配对状态，不能将它们解读为独立病例数。

| 比较 | 结果 | 状态数 / 146 | 病例宏比例 (95% CI) | 覆盖病例 |
|---|---|---:|---:|---:|
| ANSWER vs DEFER | 两者都正确 | 39 (26.7%) | 0.267 [0.167, 0.380] | 20 |
|  | Expert 破坏 Base 正确答案：ANSWER 对、DEFER 错 | 18 (12.3%) | 0.123 [0.053, 0.207] | 10 |
|  | Expert 纠正 Base：ANSWER 错、DEFER 对 | 25 (17.1%) | 0.170 [0.087, 0.263] | 13 |
|  | 两者都错 | 64 (43.8%) | 0.440 [0.317, 0.567] | 26 |
| ASK vs ANSWER | 两者都正确 | 46 (31.5%) | 0.317 [0.203, 0.433] | 21 |
|  | ASK 退化：ANSWER 对、ASK 错 | 11 (7.5%) | 0.073 [0.033, 0.120] | 10 |
|  | ASK 纠正：ANSWER 错、ASK 对 | 10 (6.8%) | 0.070 [0.027, 0.123] | 8 |
|  | 两者都错 | 79 (54.1%) | 0.540 [0.420, 0.660] | 32 |
| ASK vs ANSWER | 正确性不变 | 125 (85.6%) | 0.857 [0.787, 0.920] | 49 |
|  | 正确性改变 | 21 (14.4%) | 0.143 [0.080, 0.213] | 15 |

Expert 在 25 个状态修正 Base，同时在 18 个状态破坏 Base 的正确结果。ASK 仅在 10 个状态纠正、在 11 个状态退化。主成本下 ASK 相对 ANSWER 的病例宏 Accuracy 差为 -0.003（95% CI `[-0.060, 0.057]`），Utility 差为 -0.013（`[-0.070, 0.047]`）；状态池化差分别为 -0.0068 和 -0.0168。当前数据支持“Expert 有互补价值且也有伤害风险”，不支持把 DEFER 或 ASK 固定用作所有状态的策略。

## ASK 信息价值与限制来源

| ASK 后观测分组 | 状态数 | 纠正 / 退化 / 不变 | Accuracy 差：ASK−ANSWER，病例宏 (95% CI) | Utility 差：ASK−ANSWER，主成本病例宏 (95% CI) |
|---|---:|---:|---:|---:|
| 全部 ASK | 146 | 10 / 11 / 125 | -0.003 [-0.060, 0.057] | -0.013 [-0.070, 0.047] |
| 复核后仍 Unknown | 98 | 3 / 7 / 88 | -0.026 [-0.070, 0.015] | -0.036 [-0.084, 0.005] |
| 非空、非 Unknown、新文本代理 | 48 | 7 / 4 / 37 | +0.027 [-0.134, 0.188] | +0.017 [-0.139, 0.178] |

患者模拟器最终返回 Unknown 的比例为 **98/146（67.1%）**；111 次 bounded review 尝试中有 13 次接受复核答案。48 个回复满足“非空、非 Unknown 且文本相对先前公开状态新颖”这一代理条件。此代理仅表示词面新颖，**不等于新增临床有效信息**。代理组状态池化的 ASK−ANSWER Accuracy 差为 +0.0625、Utility 差为 +0.0525；但病例级区间很宽且包含零。无代理组病例宏 Accuracy 差 -0.026、Utility 差 -0.036，区间也包含零。13 个接受复核的状态没有观察到最终正确性改变。

因此，当前最明显的近端瓶颈是信息供给/Unknown 覆盖：多数 ASK 没有形成可用的非 Unknown 回复；同时有回复的状态中仍有 ASK 退化，说明提问选择、回复质量、Base 对回复的利用都可能限制收益。本批观察无法把三者作因果拆分。没有删除失败 ASK 状态，也没有用 Gold 生成患者回复。

## Q Advantage 与状态特征可学习性

优势分布先从动作最终正确性重建 gross advantage（即补回采集时 ASK=0.05、DEFER=0.60 成本），避免把原采集成本误认为能力差异；成本敏感标签则按指定成本再次计算。

| Gross 优势 | 正 / 零 / 负状态 | 病例宏均值 (95% CI) | 平均绝对值 | 中位绝对值 |
|---|---:|---:|---:|---:|
| ASK−ANSWER | 10 / 125 / 11 | -0.003 [-0.060, 0.057] | 0.144 | 0 |
| DEFER−ANSWER | 25 / 103 / 18 | +0.047 [-0.083, 0.173] | 0.295 | 0 |

主成本 ASK=0.01 下有 10 个正 ASK Advantage 状态，状态池化平均净优势 -0.0168；DEFER=0.05 下有 25 个正 DEFER Advantage 状态，平均净优势 -0.0021。92/146 个状态三种动作的 gross correctness 完全相同。网格中出现的正标签数量、成本净优势、绝对值和置信区间逐成本列于 `advantage_by_cost.csv` 和 `q_advantage_distribution.csv`。

轻量特征诊断只使用公开状态文本：折内拟合 unigram/bigram TF-IDF，加轮数、长度、问号/数字等结构特征；按病例做固定 5 折交叉验证；Ridge `alpha=1.0`，未做超参数搜索；对比每折的常数均值基线。没有使用窗口 A checkpoint，也没有训练 Router。

| 标签 | Ridge MAE | 常数均值 MAE | Ridge 相对 MAE 差 (病例 bootstrap 95% CI) | OOF 状态 R² |
|---|---:|---:|---:|---:|
| Gross ASK−ANSWER | 0.225 | 0.153 | +0.072 [0.053, 0.091] | -0.063 |
| Gross DEFER−ANSWER | 0.402 | 0.329 | +0.073 [0.043, 0.105] | -0.175 |

正的 MAE 差表示 Ridge 劣于常数基线；常数基线在 ASK 标签的 45/50 个病例、DEFER 标签的 39/50 个病例误差更低。该结果表明当前这一组稀疏文本/结构特征没有显示跨病例 Advantage 预测信号；它不能证明所有表征都不可学习，也不能替代窗口 A 的正式评估。

## K=1 噪声诊断与重复采样计划

可观测数据质量信号：438/438 动作格式有效；146/146 ASK 转移结构有效；token 用量记录完整，所有 finish reason 为 stop；Base/Patient/Expert API 调用分别为 438/257/146，审计未发现重试。推理配置 temperature=0、patient_temperature=0、top_p=1。与此同时，每个 state/action 只有一次结果，所以无论采集配置如何，都无法从当前轨迹估计真实回报方差、可重复性或稳定 Q。可见的潜在标签噪声来源包括患者回复 Unknown/复核覆盖、提问/答案变化，以及 3 个已标记的题干/选项语义异常状态；格式成功不代表语义标签没有噪声。

不调用模型的 K=3 预算估算：

| 方案 | 病例 | 状态 | 额外动作轨迹 | 估算额外 API 调用 |
|---|---:|---:|---:|---:|
| 定向诊断子集：近零优势、ASK Unknown、Base/Expert 分歧中按病例抽取并去重 | 11 | 32 | 192 | 约 374（Base 192 / Patient 118 / Expert 64） |
| 当前 50 例全部达到 K=3 | 50 | 146 | 876 | 约 1,682（Base 876 / Patient 514 / Expert 292） |
| 完整 70 例官方训练病例池达到 K=3 | 70 | 205 | 1,407 | 约 2,702（Base 1,407 / Patient 826 / Expert 469） |

11 例是本报告提出的小规模诊断设计，不是有统计功效保证的最小样本量。70 例估算包括当前 50 例的两次补采，以及剩余 59 个公开状态从零采三次。调用数按本轮每动作平均调用量外推，仅供资源规划；本轮没有进行任何重复采样。

## 可学习性判断

1. **标签空间有事后理论收益**：主成本下 Oracle 比 Always ANSWER 高约 20.7 个点 Accuracy、19.9 个点 Utility。
2. **可直接观测的动作收益稀疏且不稳定**：ASK 只有 10 个 gross 正优势状态；DEFER 有 25 个，同时有 18 个 Expert 破坏状态。92 个状态三动作结果完全一样。
3. **当前特征没有展示跨病例学习信号**：固定 Ridge 诊断差于常数均值基线；每个标签只有一次 rollout，真实目标噪声尚不可量化。
4. **判断**：理论上有按状态选择的价值，但仅凭这 50 例、K=1 结果，真实 Router 的泛化收益尚未得到证据支持；以当前轻量公开文本特征观察到的可学习性偏弱。Oracle 上界不可当作 Router 预期成绩，窗口 A 的训练/验证结果需独立报告。
