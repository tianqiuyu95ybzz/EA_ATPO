# Attempt09 阶段结论与下一步决定

## 五个问题的回答

1. **EA-ATPO 是否优于 Always Answer？** 在这 20 例开发集上是 4/20 对 2/20，配对差 +10 个百分点；2 例只被 EA-ATPO 答对、0 例退化，病例 bootstrap 95% CI 为 [0, 25] 个百分点。区间包含零，而且 Always Answer 仅 6/20 输出可按评分规则解析，因此目前不能确认 EA-ATPO 有稳健优势。
2. **EA-ATPO 是否优于 Original ATPO？** 否。当前比较是 4/20 对 7/20，EA-ATPO 比 Original 少 3 例；配对差 -15 个百分点，区间 [-30, 0]。但 Original checkpoint 只有 2 次更新、训练 2 个病例，结果不能代表充分训练的 Original ATPO。
3. **CONSULT 是否有独立价值？** 尚无证据。3 个 CONSULT 状态的同状态直接回答反事实中，0 次纠错、1 次退化、2 次不改变正确性。
4. **DEFER 是否有合理使用场景？** 本轮没有验证到。20 例恢复评估没有 DEFER；训练的 4 次全在 ASK→CONSULT 后发生且均错，净 episode 回报均为 -0.85。不能据此设计 DEFER 的可靠阈值。
5. **Critic 是否可靠？** 否。10/10 步 EV 为负，平均 -28.85；Return 在后几步方差约 0.01，而预测残差方差仍更大。不能把当前 Critic 预测用于动作价值比较或训练结论。

## 决策

**暂不扩大 PPO，也不增加网络模块或 Loss。** Attempt09 证明了协议修复后四动作训练链路能完成 10 次更新、checkpoint 能恢复；它没有证明四动作策略优于基线，也没有证明 Critic 可提供可靠价值估计。

下一阶段若继续，先做测量与基线对齐，而不是扩量训练：

1. 为动作选择加入可审计的前缀 logit / 采样概率和首位动作标记校验，解决当前解析器可从回复任意位置发现动作标记、真实动作概率无法复原的问题。
2. 在新的病例隔离集合上复做 Always Answer、预算对齐的 Original ATPO 与 EA-ATPO；同时报告可解析率，确保比较不是由输出格式差异主导。
3. 在开启更长训练前先确认 Critic 冷启动后的 Return 校准和跨病例验证表现；不以 EV 为负的 checkpoint 作价值路由依据。
4. 只有当 CONSULT 有纠错且不造成相近规模退化、DEFER 出现正收益样本、Critic 在病例隔离验证集不再持续负 EV 时，再评估是否增加训练预算。

当前建议保留 Attempt09 step10 Actor/Critic、完整训练轨迹与本报告，结论标记为“工程 smoke 已恢复；策略有效性未成立”。本阶段没有启动新 PPO 训练。
