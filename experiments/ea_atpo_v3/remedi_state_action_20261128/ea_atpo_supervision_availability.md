# EA-ATPO V3 监督可用性

| 层级 | 本轮数据 | 可支持的结论 |
| --- | --- | --- |
| A 行为监督 | 去历史 Pilot 后的 11,935 个医生前缀状态，3,414 ASK、1,572 ANSWER、157 MIXED、6,792 OTHER | 4,986 个明确 ASK 或 ANSWER 标签可做二动作 DPL imitation。动作来自原医生的实际选择 |
| B 观察结果 | 3,571 个含问询成分的状态中，3,508 有患者反馈，2,656 反馈带新增有效标注槽值，2,088 同时取得目标槽上的新值 | 历史信息获取的描述性证据。无患者反馈 63 窗口，有反馈但无新增有效槽值 852 窗口，有可识别目标且反馈未命中目标槽 1,031 窗口。这些条件可重叠 |
| C 反事实收益 | 同状态可比较的动作结果 0，DEFER 可用 0，Q-guided 可训练样本 0 | 无法估计同状态净收益、训练三动作 Router，或声称处置效果 |

在有可评目标且有反馈的 3,189 个窗口内，2,158 获得至少一个目标槽的反馈，比例 67.67%。目标槽命中按槽名计算，通用槽不计入，尚不能确定同一槽是否对应所问的同一症状。按有槽标签的 3,247 个窗口计，275 次重复此前的槽和值签名，约 8.47%。1,365 次询问已有值的槽，约 42.04%，可能只是询问不同值。全体 3,571 个含问询成分窗口平均已知槽数从 1.98 增至 2.60。增量仅反映已标注、此前未见的槽值，开放式质量或医学效用需要其他依据。后续医生动作按官方标签多选计数。

ANSWER 的 1,572 个参考组全部有动作参考，377 有有效槽参考，325 有医疗槽实体参考。359 个标注医疗槽实体对中，210 个在原回复字面找到，1,912 个有效标注片段中 1,910 个与原回复对齐。独立模型的 Action Consistency、Slot Consistency、Medical Entity Coverage 和 Medical Correctness 均待测。历史医生回复可作参考，未来反馈及医生回复均未被当作当前时点的 DEFER 参考。

## 专项数据衔接

- **IMCS-21**。已有正式文档和项目审计描述 DDP 以显式症状为初始状态，枚举症状查询、返回隐含状态并在轮次预算内提交疾病分类。可比较不同基于症状代码的 ASK 策略，前提是核验数据许可、复用现有模拟器并解决 DDP 输入与发布 train/dev 字段不一致的问题。显式与隐式字段必须分离，POS、NEG、NS 保留三态，未标注为未知。记录 `diagnosis` 可评官方十类任务，人工报告中的诊断是另一字段，原始病种标签的独立临床确认链仍待核验。此次以已有源码审计、论文和版本说明为依据。 [IMCS-21 论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9848052/) · [作者仓库](https://github.com/lemuria-wchen/imcs21)
- **DDXPlus**。现有验证原型的初始视图只公开 `INITIAL_EVIDENCE`，后续 ASK 按证据码释放症状或病史，`PATHOLOGY` 和鉴别分布留给离线评价。官方合成病种标签可对已冻结的同初始视图定义 Standard Oracle 的分类上界。Base-Protecting Oracle 用事后精确匹配判定正确时保留 Base，否则返回标签。在精确标签分类中，两者可能给出相同标签。这两种 Oracle 都以离线标签为条件，尚需验证证据依赖和默认值规则、跨划分重复与真实可用专家能力。 [DDXPlus 发布](https://mila-iqia.github.io/ddxplus/) · [官方数据字段](https://github.com/mila-iqia/ddxplus)
- **MedDG** 沿用补充实体和对话的角色。ReMeDi、IMCS-21、MedDG、DDXPlus 各自报告，跨任务不汇总为一个 Accuracy。

63 的已检查项目目录内未定位到可复用的 IMCS-21 / DDXPlus 原始包，旧 PFS 挂载不可见。本轮只核查现有报告与代码，没有重新下载、构造、运行这两个数据集。
