# ReMeDi ASK/ANSWER 最小有效性验证

在 63（amax）执行。数据固定为 `ca6e2b28a2176fde71869369fb0e49088815de7b` 对应的受控数据构建结果。复核 Train/Dev 输入哈希。本轮只打开 Train 与 Dev 的数据，官方 Test 保持冻结。更新的是实验和审计记录，已冻结的数据包保持原样。

## A 历史 ASK 的信息获取

仅分析明确的单动作 ASK，排除 MIXED 和历史 Pilot。每条以官方标注记录既有槽、医生询问、实际反馈、反馈新增值和下一个医生轮。此前已问过的槽值签名记为重复，已有同槽其他值单列。以槽名匹配目标，无法区分同一槽的不同症状主体。多目标窗可计入多个槽类别。

| Split | 单动作 ASK | 目标槽新增 | 仅非目标槽新增 | 有反馈无新增 | 无反馈 | 平均已知槽数变化 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| Train | 1,433 | 847 | 225 | 340 | 21 | 1.94 → 2.57 |
| Dev | 254 | 143 | 46 | 63 | 2 | 1.87 → 2.48 |

按有反馈的目标槽询问统计，Dev 症状槽 73/110、时长槽 33/53、检查项槽 11/35、用药槽 7/18 获得该槽新值。症状槽 111 次询问中有 9 次重复历史查询签名、79 次此前已有该槽的某个值。槽内已有值可能属于不同症状，故以这两种口径分别描述。Dev 中目标槽新增组后续有 38/143 个 Recommend、12/143 个 Diagnosis，无新增组分别为 13/63 和 3/63。后续动作可多选。组间差异只描述观察到的历史路径，无法识别因果影响。

历史问询确实能获得新增结构化信息，Dev 中明确命中目标槽的新值出现在 143/254 个窗口。实际反馈率、目标值命中率及最终回复结构指标分别报告。

## B 同状态直接回答与历史回放配对

冻结原始 `Qwen/Qwen3-8B` revision `b968826d9c46dd6066d109eabc6255188de91218`，模型文件 SHA-256 验证通过。在 GPU 0 用 BF16、batch 1、贪心解码、关闭 thinking、最多 96 个新 token、seed 20261128。环境为 Python 3.11.15、PyTorch 2.11.0+cu130、Transformers 5.6.0、Accelerate 1.13.0。使用同一结构化提示词辅助判断模型自报槽名。槽指标为集合匹配的 micro precision/recall。实体覆盖为原参考标签的 `value1` 在生成回答中的规范化字面命中，可能漏计同义词，无法核验否定、完整性和医学正确性。未解析输出按零命中保留分母。

直接回答样本来自具有可评槽或实体且符合特征边界的历史 ANSWER 状态。Train 用预设哈希抽取 12 条工程对照。Dev 112 个直接回答参考组中，使用满足既有特征边界且存在结构化参考的全部 **21** 条。Dev 配对另选 **8 个不同对话**，由历史 ASK 状态起步，有真实反馈，且反馈后观察到的医生 ANSWER 有槽或实体参考。固定哈希排序每对话保留一个窗口。两臂均用反馈后观察到的同一医生结构参考**离线评分**。初始臂输入到 ASK 前，回放臂额外输入历史提问和反馈，两个输入都不含后续医生回答或参考标签。比较的是加入整段历史问答后对后续结构参考的对齐。

| 队列 | 可解析输出 | 槽 precision | 槽 recall | 实体覆盖 |
| --- | ---: | ---: | ---: | ---: |
| Train 直接回答 | 11/12 | 8/42 | 8/12 | 2/8 |
| Dev 直接回答 | 21/21 | 11/89 | 11/21 | 6/23 |
| Dev 配对，回放前 | 8/8 | 4/20 | 4/8 | 3/10 |
| Dev 配对，回放后 | 8/8 | 5/28 | 5/8 | 4/10 |

8 组配对的病例均值变化，槽召回与实体覆盖各为 +12.5 个百分点，各有 1 组改善、7 组持平。病例 bootstrap 10,000 次，两项探索性 95% 区间均为 [0, +37.5] 个百分点。回放后模型报出更多槽，精确率从 20.0% 降至 17.9%。样本筛选要求有结构化参考且规模很小。直接回答对历史结构参考的对齐还有改善空间。当前观察不足以确认稳定的 ASK 带来回答质量提升，不外推至自主 ASK 或临床正确性。

共 49 次生成，48 次成功解析，生成段 60.17 秒，PyTorch 峰值 15,777 MiB。以查询时点 GPU 0 空闲启动，运行前后计算进程快照一致。病例、逐条输出、选样与日志留在受控服务器目录。只发布汇总和代码。原始权重的生成配置含采样参数，Transformers 在贪心模式提示忽略。

```bash
export PYTHONPATH="$BUILDER_DIR"

  --source "$FROZEN_PRIVATE_DATA" --run "$NEW_RUN"

  timeout 420 python -u validate_remedi.py infer --run "$NEW_RUN" --weights "$MODEL_DIR"
```
