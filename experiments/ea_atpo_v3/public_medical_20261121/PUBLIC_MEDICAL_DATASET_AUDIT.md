详细分母、角色数和轮次分布见 CSV 和 turn_distributions.json。轮次是消息数；多轮定义同时至少两条患者与两条医生消息。角色为数据集标签，并不证明说话者身份。完整对话数一列仅验证有双方非空消息，不能证明完整医疗经过或回答正确。≥20 字符仅为文字长度代理，不能证明医学内容、诊断或建议正确；中文是任意 CJK 字符，不是语言占比。结构异常只涵盖空消息、未知角色或缺失一方，不能代表所有质量问题。ReMeDi 的 20 为规范化后的重复行数，2 条含空消息；二者不一定不重合。没有人工临床审核。

ReMeDi 来源论文称采集自春雨医生多科在线问诊（[论文](https://arxiv.org/abs/2109.00430)），标注部分保留 patient/doctor 及多轮上下文。MedDG 论文描述消化系统疾病领域的在线问诊（[论文](https://arxiv.org/abs/2010.07497)），领域窄但样本量较大。两者可映射为原始上下文与下一位医生回答；这不等于每个医生回答都是最终诊疗建议，也不能证明回答最新或正确。DISC 的 200 条是首尾各100，其中来源字段分别为 meddial 和 CMeKG；官方描述包含重构和知识图谱数据，assistant 不是均可视为原始医生。Aquila 官方卡列出混合问答及多种源，并非都是真人多轮。MedDialog 官方中文训练文件以字符串序列表示，观察到病人/医生标签；前200条非随机，不能代表全库；目标 GitHub 链接 404，但官方 UCSD 加载脚本所列 Google Drive 文件可流式读取。

抽样方式：ReMeDi 和 MedDG 分别读官方 base 与 train 全部；DISC 读数据查看器首尾各100；Aquila 从五个分位偏移各100；MedDialog 读官方中文 train 前200。后两种 API 和前缀抽样均不保证总体代表性。DISC/Aquila viewer 数据快照 API 不支持 revision pin；已记录观察到的 repo revision 和样本 SHA，但不能证明该快照与 revision 字节一致。Google Drive 的 MedDialog 完整源约1.665 GB，只下载首段并存为200条样本；样本 SHA 不是全量文件 SHA。

## ATPO 重叠

对历史 pilot public states 中抽取的 336 个长度≥10的规范化公开字符串，逐条对比本次读取数据中的消息，五组命中均为 0。此检查只覆盖公开 pilot 的精确单条消息，不覆盖所有 ATPO 训练数据、语义重述、跨语料重复、病例同源及冻结集，因此不能宣称无泄漏。未读取冻结集。

## 推荐

优先以 ReMeDi-base 为多科、原始对话候选，并在数据权利与隐私处理确认后，用 MedDG train 构建消化科补充对照；先做跨库病例/近重复去重与分组，不盲目混合。单一 ReMeDi 体量小；单一 MedDG 数量较大但领域偏窄；组合潜在覆盖更广但同源、重复及配比风险未评估。DISC/Aquila 暂不作为质量优先的默认混合源：来源混杂、存在重构或单轮问答；MedDialog 前缀样本仅 48/200 多轮且权利待核验，暂不默认混入。所有建议均为候选，不代表已确认授权、临床质量、模型提升或正式训练许可。

已对 ReMeDi/MedDG 各前20例做格式转换 smoke，分别产生232/212个以每次医生回复为终点的上下文样本，原文保存在 private，未训练。转换只证明结构可映射；尚未验证 Qwen chat template、完整序列长度、跨库患者级分组和数据权利，不可直接作为生产训练集。保留独立评测的 Gold review、both_medical、quality 及 A/B 比较方向；both_medical 的具体实现和 A/B 设计仍需后续核实，不在此静默改写。独立 Gold 未确认，不能用公开训练集或历史标签充当测试金标准。

CSV 另给出医生回复命中有限中文医学关键词的记录数及最后角色为医生的记录数，二者也不证明医学内容有效或对话完整；例如 ReMeDi 分别为 1,380 和 1,520，MedDG 为 13,448 和 12,526。每例都有双方消息仅是结构检查，结尾为患者的记录不应自动视为完整诊疗答复。

转换 smoke 的交替角色检查：ReMeDi 232 个前缀中 199 个、MedDG 212 个前缀中 176 个包含连续同角色消息；均以 user 开始。转换保留原轮次，不保证符合所用 Qwen chat template。正式实现必须验证模板并采用明确的相邻同角色合并策略，确保只对当前目标医生回复计算 loss，防止重复监督历史助手消息；当前脚本不含 loss mask，因此不适合直接启动 SFT。
