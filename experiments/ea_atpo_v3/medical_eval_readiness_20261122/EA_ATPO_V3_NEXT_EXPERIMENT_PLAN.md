# EA-ATPO V3：下一阶段正式实验草案

**状态：设计完成，所有运行与训练开关关闭。** 研究定位维持医疗信息获取与鉴别诊断，动作 ASK / ANSWER / DEFER，Oracle 为理想专家上界，Q-guided Distillation 为待验证 Router。下面是计划与门槛，不是已验证的性能或训练批准。

## 现有证据与前置门槛

旧中文 Pilot 的 50 次初始回答、50 次历史追问回放是探索性工程结果；20 对人工质量评分尚未开始，医生普通回复不是 Gold。DDXPlus 既有 50 例 Qwen3-8B 初始诊断及 Oracle 重放仅是合成标签分类的探索；官方 train/validation 有精确重复且无患者 ID，患者级隔离尚未确证，测试集保持关闭。旧 DDX 病例是合成病人，不得称为真实临床病例。当前 Qwen3-8B 原始 checkpoint 不应称作 SFT→ATPO 最终模型。冻结具体可用 Base、数据版本、解码与 Router 特征之后，才能开始配对结果采集。

必须先解决：1）来源使用权与隐私审查；2）可验证、与当前决策时刻/输出类型相匹配的 Gold；3）跨 split 精确重复、近重复、已知历史数据污染和无患者 ID 的限制；4）DDX 患者 evidence 默认值、类别/多选和依赖路径对官方规则的一致性测试；5）规定实际可用 ASK 反馈、问题解析和丢失/不确定处理；6）正式质量、安全评分、标注一致性、抽样方案和样本量/功效在解盲前预注册；7）按病例配对的共享状态与成本账本。若任何门槛未通过，该数据/动作的相应指标为 N/A，不将旧 test 或 400 例 Frozen Holdout 打开补数。

DDXPlus 可在满足去重及模拟器门槛后用于合成病种分类；PATHOLOGY 是生成病种标签，不是完整建议的事实 Gold。即使病种最终已知，初始信息不足时“正确病种”也不证明该时刻可被安全判断。IMCS-21 可在权利与标签链核实后作为中文辅助；ReMeDi 的医生参考和历史患者反馈只支持经批准的人工质量评审与原问题回放，不可当患者对任意新问题的答案。

## 固定策略及配对协议

每例在相同的可见初始状态、同一冻结 Base、同一候选动作/规则下按 case_id 独立重置环境；分离患者模拟器、离线 Gold、Router 特征和评测器。对相同病例配对记录动作、问题、回应、Base 输出、有效性、实际成本和终止状态；不将其他策略输出或未来医生信息送给任一策略。ASK 若缺可用患者反馈或语义匹配失败，标为动作不可用或单独报告失败，不得偷偷补造；报告共同可评病例和全量分母。观察性回放的可用性依赖后续历史，筛选可能引入偏差，不能当作前瞻自主交互。

| 预设策略 | 规则及限制 |
|---|---|
| Always ANSWER | 当前 Base 给出最终答案。 |
| Always ASK | 对预先定义的有效问题执行一次 ASK，获得真实或经核验模拟的对应反馈，再由同一 Base 回答；不可用时报告不可用并单列分母。 |
| Oracle DEFER A | 有合法且与任务/时点匹配的目标时，DEFER 返回 Gold；否则 N/A。这是离线上界，不是可部署 Expert。 |
| Oracle DEFER B | DEFER 后按事后 Gold 判断 Base，正确则逐字保留 Base，否则返回 Gold；只作离线上界，不进入 Router。 |
| Q-guided Router | 公共状态和合法动作输入预测 Q / 蒸馏策略；先选 ASK/ANSWER/DEFER，ASK 后按冻结策略继续。训练前需要合法离线反事实和动作标签；测试时不得输入 Gold、事后正确性、未来事实或对手策略输出。 |

A 与 B 在严格标准病种标签相等且 Oracle 完美时，正确 Base 和 Gold 是同一标签，因此表面 accuracy 和保护率可能必然相同；不能据此证明保护机制有额外收益。若评完整自由文本，必须有该时点可用的可信完整目标或独立盲评，不能借助病种标签虚构完整 Gold。对 ReMeDi 当前未有适配 Gold，Oracle 两种策略均 N/A。

## Balance 指标、统计和成本

诊断分类在合法标签可用时报告 Accuracy；质量评估在独立人工评分可用时分别报告正确性、完整性、安全性，以及严重错误（无法判断单列）。核心路由指标：Base 正确答案保留率、错误纠正率、DEFER rate、DEFER precision（事先固定纠正/调用的定义）、ASK rate、有效 ASK rate（可核验新信息和临床有用分别报告）、ASK 之后有效新证据数、动作分布和相对 Always ANSWER 的配对改善/恶化。缺乏验证标签或评分时不把未测计为 0。

Utility 以每病例 `Quality - c_ask * n_ask - c_defer * n_defer - safety_penalty` 定义。病种正确性可作为该受限子任务的 Quality；自由文本 Quality 的 1–5 评分归一化、权重、严重错误惩罚、缺失值处理及费用单位在解盲前确定，未冻结即 N/A。按动作实际发生记录，费用恰扣一次；对照和 Router 使用相同网格 ASK 0.01/0.05/0.10 × DEFER 0.05/0.10/0.20/0.60。主费用点及多重比较策略必须在训练/验证前确定，不从测试中挑胜。报告每种费用和单独的质量/安全指标，不靠调成本制造优势。

同一病例聚合后按 case_id 配对 bootstrap 95% CI，记录重采样次数、随机种子与无效分母；稀少条件事件报告分子分母及不稳定性。重复采样不是新增样本；先进行独立病例数与功效/精度规划，不给未查证患者 ID 赋值。20 对人工样本仅做可行性和盲评一致性分析，不作为正式效果的充分证据。

## 消融与反退化

固定 Base、样本、可用动作、预算和评估器，比较：Q-guided Router 与 Always ANSWER/ASK/DEFER；去 ASK 或去 DEFER；无成本与各预注册成本目标；只用可见信息/去除不确定性特征；无 Q 蒸馏的同预算对照；真实反馈与已核验模拟反馈分别报告。Oracle A/B 是上界对照，不是可部署消融。每组报告 ASK/ANSWER/DEFER 的计数和比例、对动作类别的选择熵/占比，标注合法动作不可用率；若 Router 基本恒定选择单一动作，应报告退化及其效用，不因接近某基线而排除样本。训练/验证只在病例隔离后进行，validation 选超参/成本，冻结模型和方案后才可按授权的一次性独立 test 评估；禁止用 test 或 Frozen Holdout 调参。

## 通过标准

在有身份与隐私权限、标签可追溯、独立性审计、分母和事先固定质量/安全单位的前提下，先完成可复现的小样本 CPU/模型协议核验，再进行独立验证。判断 ASK 有价值需可验证信息与质量变化，判断保护需比较 Base 原正确病例，判断 DEFER 有效需可信 Gold 和真实可部署专家（本计划仅估 Oracle 上界）；Q-guided Router 要显示非退化动作选择，并以预注册成本下的配对效用差及 CI 与 Always ANSWER 比较。现阶段所有这些均为待验证假设。
