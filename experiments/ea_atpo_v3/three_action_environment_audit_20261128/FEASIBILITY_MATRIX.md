# 三动作环境可行性矩阵

| 评价项目 | ReMeDi | IMCS-21 | DDXPlus |
| --- | --- | --- | --- |
| 中文医疗对话 | 已确认支持 | 已确认支持 | 不支持 |
| 真实多轮交互 | 已确认支持 | 已确认支持 | 不支持 |
| 官方患者模拟器 | 不支持 | 已确认支持 | 已确认支持 |
| 指定症状 ASK | 不支持 | 部分支持 | 已确认支持 |
| ASK 后状态更新 | 部分支持 | 部分支持 | 已确认支持 |
| 同病例重复分支 | 不支持 | 部分支持 | 已确认支持 |
| Base ANSWER 评价 | 部分支持 | 部分支持 | 已确认支持 |
| 同状态 Gold Oracle | 不支持 | 部分支持 | 已确认支持 |
| Base-Protecting Oracle | 不支持 | 部分支持 | 部分支持 |
| 同状态三动作比较 | 不支持 | 部分支持 | 部分支持 |
| 数据许可 | 部分支持 | 尚未核实 | 已确认支持 |

- **真实多轮交互**指语料含真实医患曾发生的多轮对话。重放或规则环境响应均不构成真实患者对新问题的实测交互。IMCS-21 的官方模拟器指作者随 DDP 发布的第三方规则代码，需适配作者数据版本。DDXPlus 指作者仓库发布的 BASD/AARLC 合成环境。环境能力已由代码确认，当前 amax 的运行状态仍待核验。
- **指定症状与重复分支**指可选择不同结构化证据并重启同病例。ReMeDi 的原问答回放可以推进历史状态，无法为可变询问提供病例反馈。IMCS-21 的接口支持这类操作，许可、输入桥接和 Base 公开边界仍待确认。DDXPlus 固定病例索引和初始证据后具备此能力。
- **ANSWER 与 Oracle**。ReMeDi 只具备历史结构参考及已报告的开放式评分方法。IMCS-21 有十类标签，可定义条件性离线上界，独立临床来源及许可仍待确认。DDXPlus 的 `PATHOLOGY` 明确可用于标签评分和 Standard Oracle 的定义。Base-Protecting 与三动作协议没有现成官方 V3 入口，需项目接线。DDXPlus 的已确认证据限于合成标签范围。
- **部分支持**指已经找到明确组成条件，仍有任务或工程门槛。数据许可度量的是相应发布的授权证据。IMCS-21 的 UNKNOWN 不构成批准，ReMeDi 的 MIT 声明和上游权利分开。
