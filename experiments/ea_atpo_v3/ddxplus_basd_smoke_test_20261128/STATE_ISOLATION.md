# BASD 状态隔离的静态核对

本文件记录待验收契约。运行状态为未执行。

| 来源 | 字段或位置 | 允许进入模型 |
| --- | --- | --- |
| 初始化返回元组 | 索引 0 为 `init_state` | 仅其已公开证据的白名单投影 |
| 初始化返回元组 | 索引 1 为 `self.disease` | 否。用于独立评价 |
| 初始化返回元组 | 索引 2、3 为差分诊断索引、概率 | 否 |
| 初始化返回元组 | 索引 4 为 `self.disease_severity` | 否 |
| 环境实例 | `target_state` 与尚未被查询的病例证据 | 否 |
| ASK 返回元组 | 索引 0 为更新后的状态，索引 1 为奖励，索引 2 为 `done` | 只允许从索引 0 投影出已公开字段，reward 与 done 留在控制或评价端 |

公开观测的允许键为 `observed_evidence`，内容只含已公开的证据码和值。若以后实验协议纳入人口学或公开对话，需先单独固定允许键。本次单病例验收的最小观测只用初始证据和一次新证据。病例定位键及隐藏证据数量只留在审计记录。评价端可读取病种、鉴别诊断、严重程度以及环境内部目标，Standard Oracle 只在评价端读取同一病例 Gold。

实际验证需对两次独立初始化的公开 JSON 作完全比较，并核查单次查询前后的观测差异。JSON 中不应出现新的其他证据或任何评价字段，且整个评估对象不能被模型日志序列化。当前未产生任何病例状态，不能据静态源码宣布隔离验收通过。
