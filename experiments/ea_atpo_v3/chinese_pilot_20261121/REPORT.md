# 中文医疗咨询探索性 Pilot（2026-11-21）

## 实际执行

没有找到 A 的 `pilot_samples.jsonl`。从现有 ReMeDi-base 以固定 ID 哈希抽选 50 个不同对话记录，条件为初始患者历史之后有原医生问句、紧接患者反馈和下一医生回复；无按模型结果或诊断正确性筛选。数据是历史咨询，不是临床验证 Gold。50/50 的源 ID、初始前缀、角色和原始先后顺序通过核对；患者级近重复与历史使用无法排除。

所有 GPU 当时均有其他计算进程，包括低利用率卡，按用户要求未抢占；既有 Base 端口未运行，未调用其他服务。使用项目原始 `Qwen/Qwen3-8B`，revision `b968826d9c46dd6066d109eabc6255188de91218`，非 SFT+ATPO 最终模型，无 Adapter，CPU 8 线程、贪心、关闭 thinking。初次 3 例共 6 条输出达到 96 token 上限，已停止并单独保留，不纳入正式结果。重试在同样模型和病例上要求最多两句话，50 例两种状态的 100 次生成全部非空且以 EOS 结束，总生成耗时约 655 秒；完整逐病例原始输出和上下文留在 private。EOS 只证明生成结束，不证明回答医学正确。

## 同病例策略与可计算指标

| 策略 | 完成病例 | 可确认结果 |
|---|---:|---|
| Always ANSWER | 50 | 初始上下文生成，50/50 非空且 EOS |
| Always ASK Replay | 50 | 原医生追问及紧随的患者反馈后生成，平均 1 次历史追问；并非模型自主 ASK |
| 简单规则 Router | 50 | 49 ANSWER、1 ASK、0 DEFER；平均 ASK 0.02 次、DEFER Rate 0% |
| Always DEFER | 0 可公平评测 | 医生的后续回复是在患者反馈**之后**写的，作为初始状态参考会泄露额外信息；保存在本地仅供有上下文的后续审核 |

Router 的 ASK 规则仅检查初始末条患者消息是否含“不知道/不清楚/不确定”，且利用了历史回放是否可用；该词面代理不能证明缺失信息重要，而回放可用性是事后信息，不代表可部署策略。没有依据构造高风险标签，未执行 DEFER。Router 在 49 例复用与 Always ANSWER 同一输出，1 例复用回放回答；只有 1 例有可能出现质量变化，改善或恶化尚未知。

所有 50 个历史患者反馈非空且按时间可追溯，但 Useful ASK Rate 未经质量/临床审核，不能将“非空”等同于有用。未发现可信自动评估服务，没有将其他人的服务用于患者数据。已私下生成 20 个配对病例的名称盲化人工审查队列，**人工审核尚未执行**，评审者仍能看出额外反馈是否存在。Answer Quality、Critical Error Rate、逐例改善/恶化、DEFER 价值和 Utility 均未知；不能用医生回复相似度或模型对自身打分代替。`metrics.json` 的空值表示未测，不是 0 分。

预设 ASK 成本 0.01/0.05/0.10、DEFER 成本 0.05/0.10/0.20；待可信质量和安全评分后逐策略按 `Quality - ASK_cost*次数 - DEFER_cost*次数 - Safety_Penalty` 一次扣除。现在无法计算成本敏感 Utility 或声称 Router 优于 ANSWER。没有真实 Oracle 结果，也没有证据支持开启 Q-guided Router 训练。研究下一步应先完成独立盲评、审核模拟回放与可用性假设、获得与初始状态匹配的 DEFER 参考并验证数据权利。

完整细节、匿名状态行与复现入口分别见 `run_manifest.json`、`results.csv`、`README.md`。本轮没有 SFT、RL、PPO 或 Router 训练，没有读取 Frozen Holdout，没有上传患者对话、原始模型输出、Gold 或权重。
