## 同病例策略与可计算指标

| 策略 | 完成病例 | 可确认结果 |
|---|---:|---|
| Always ANSWER | 50 | 初始上下文生成，50/50 非空且 EOS |
| Always ASK Replay | 50 | 原医生追问及紧随的患者反馈后生成，平均 1 次历史追问；并非模型自主 ASK |
| 简单规则 Router | 50 | 49 ANSWER、1 ASK、0 DEFER；平均 ASK 0.02 次、DEFER Rate 0% |
| Always DEFER | 0 实际评测 | 先前保留的医生后续回复是在患者反馈**之后**写的，不能用于初始状态比较；后续审计发现至少一条初始时点医生发言同时含追问及条件性建议，需另行人工核验 |

Router 的 ASK 规则仅检查初始末条患者消息是否含“不知道/不清楚/不确定”，且利用了历史回放是否可用；该词面代理不能证明缺失信息重要，而回放可用性是事后信息，不代表可部署策略。没有依据构造高风险标签，未执行 DEFER。Router 在 49 例复用与 Always ANSWER 同一输出，1 例复用回放回答；只有 1 例有可能出现质量变化，改善或恶化尚未知。

所有 50 个历史患者反馈非空且按时间可追溯，但 Useful ASK Rate 未经质量/临床审核，不能将“非空”等同于有用。未发现可信自动评估服务，没有将其他人的服务用于患者数据。已私下生成 20 个配对病例的名称盲化人工审查队列，**人工审核尚未执行**，评审者仍能看出额外反馈是否存在。Answer Quality、Critical Error Rate、逐例改善/恶化、DEFER 价值和 Utility 均未知；不能用医生回复相似度或模型对自身打分代替。`metrics.json` 的空值表示未测，不是 0 分。

预设 ASK 成本 0.01/0.05/0.10、DEFER 成本 0.05/0.10/0.20；待可信质量和安全评分后逐策略按 `Quality - ASK_cost*次数 - DEFER_cost*次数 - Safety_Penalty` 一次扣除。现在无法计算成本敏感 Utility 或声称 Router 优于 ANSWER。没有真实 Oracle 结果，也没有证据支持开启 Q-guided Router 训练。研究下一步应先完成独立盲评、审核模拟回放与可用性假设、获得与初始状态匹配的 DEFER 参考并验证数据权利。

## 第二阶段质量核验（2026-11-21）

### 工程与历史回放

20 个评审病例、40 条 ANSWER/ASK Replay 原始输出与源对话、病例映射、随机排序密钥逐条核对；全部非空且以 EOS 结束，20/20 病例配对正确。此项只验证工程完整性。ASK 是真实历史医生问题及随后患者回复的重放，不是模型生成的自主提问；历史回放能否在新交互中得到对应回答未知。

唯一规则 ASK 的触发是患者明确表达不确定，且数据中恰好存在回放；反馈新增了先前处理情况和发生频率等细节。初始模型回答建议就医，回放后回答增加了自我处理/治疗方向和条件性就医建议。内容发生变化不等于临床质量提高，也不能仅凭对照断言变化由某一项反馈引起；医学正确性、安全性和有用性待审。

### 医生参考与真实 Router

本次检查 50 个初始时点的下一条原医生发言，关键词筛查命中两条，其中一条同一发言包含问句及条件性建议，是可能的初始状态参考；该内容未经独立医学确认，且不是完整 50 例 DEFER 对照。其余发言未做完整临床标注，不能仅凭关键词断言没有其他可用候选。原结果中未实际评测同状态 DEFER，仍为 N/A；患者反馈后的医生回复不能代替初始状态参考。

### 人工质量评审与训练决定

已整理 20 病例、40 条回答的评分表及 20 行配对表，医学正确性、完整性、安全性、严重错误、信息有效性和建议变化均为空，**无人工分数、无质量对比结论**。评审顺序及策略名称已隐藏，但额外上下文暴露使评审者可能推断实验条件，不能保证完全盲法；先前材料仅 ID 假名化，正文尚未证明去标识化，须在授权环境处理后再交给评审。评分表及规则见 `quality_audit_20261121/REVIEW_RUBRIC.md`；原始材料仅本地 private。

本轮重新校验模型索引和 tokenizer 摘要，确认此前使用原始 Qwen3-8B，未加载 SFT-ATPO 或 Adapter。所有 GPU 都有其他计算进程，无安全空闲 GPU，故未做自主 ASK 探索，也未训练。质量及安全指标、有效 ASK Rate、Utility、Router 是否优于 ANSWER 均继续为 N/A；结果不证明 EA-ATPO 性能提升，暂不能据此训练 Q-guided Router。
