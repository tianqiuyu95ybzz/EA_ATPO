# 2026-11-22 本地隐私检查

`prepare_restricted_review.py` 读取已有 private 20 例配对评审包，在新 private 目录生成随机病例关联 ID、预处理上下文、未修改的 40 条模型回答、空白评分表及单独映射；脚本对输出采用 exclusive create，不会覆盖原文。20 个上下文和 40 个回答由助手本地检查，未见明显姓名、电话或具体地址；规则仅作辅助，不保证自动识别完整。成人精确年龄泛化、部分具体日历时间隐藏；儿童年龄及相对病程因临床评审保留。原始记录不修改。

该文件仍保留可检索的原始医学叙述和必要准标识符，仅为受限内部工作副本，不是经认证匿名数据，不得对外发送。完整性、可重识别风险和数据来源权利应由有资质的隐私人员独立确认；参考 [HHS 去标识化指导](https://www.hhs.gov/hipaa/for-professionals/special-topics/de-identification/index.html) 关于组合识别风险的方法论，不在此断言该美国法律适用或已合规。人工评分不存在，不能运行质量统计。

`DEFER_AUDIT.json` 是对 50 条初始下一医生发言的本地助手文本检查摘要，3 条可能包含部分建议/判断，尚未医生认证，不足形成可比全量参考。人工结果、病例映射和原始文本均禁止入 Git。
